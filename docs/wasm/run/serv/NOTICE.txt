What we built (and what is OURS, not SERV's)
--------------------------------------------
The SERV core and servile wrapper RTL are UNMODIFIED upstream files. The only
new RTL is a thin SoC/top wrapper for the demo:

  serv_blink_wasm.v   top module `serv_blink`: instantiates `servile`, a register-
                      file SRAM (serv_rf_ram), a 32-word program ROM loaded via
                      $readmemh("count32.hex"), and a GPIO that captures the
                      32-bit store word onto an output port so the running CPU is
                      visible (gpio[31:0] counts up; blink = its LSB).
  count.S/count32.hex a tiny RV32I program (store-counter-in-a-delay-loop).

These wrapper/program files are authored for this demo and are released under the
same ISC terms for convenience; they contain no upstream SERV code.
