SERV — a real RISC-V CPU running a program in your browser
The famous smallest RISC-V (RV32I). It boots a program from ROM and stores a counter to a GPIO — watch gpio[31:0] count up at ~12.5M cycles/sec, all on your CPU.
Compiled from the SERV sources (21 Verilog files + an assembled program) by the build pipeline — the same multi-file Verilator→WASM path a linked GitHub repo would take. Apache-2.0 / ISC (olofk/serv). License & how-it-was-built →
