▶ Run on XhardTech

Fork a hardware design into your own GitHub, build it to WebAssembly in your own CI, and run it from your own GitHub Pages.

Loading…

This is a one-click setup. We create a repo in your account from a public template, write your design choice into it, and let your repo’s own GitHub Action compile the RTL to WebAssembly and publish it to your repo’s own GitHub Pages. XhardTech only orchestrates the one-time setup — the repository, the CI minutes, and the hosting all belong to you. You can edit xht.json in your new repo at any time, or uninstall the GitHub App to revoke access.
